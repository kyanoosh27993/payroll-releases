# ۰۳ — مدل دیتابیس (Prisma / SQLite)

- تعریف مدل‌ها: `prisma/schema.prisma`
- معادل SQL برای مهاجرت خودکار exe: `prisma/init.sql`
- ⚠️ **قاعده:** هر تغییری در schema باید در «هر دو فایل» اعمال شود، چون exe فاقد
  Prisma CLI است و در اولین اجرا اسکیمای خود را از `init.sql` می‌سازد
  (پیاده‌سازی: `src/lib/core/migrate.ts`).
- اعمال تغییر روی دیتابیس توسعه: `npm run db:push`
- فایل دیتابیس واقعی: `db/custom.db`

## گروه‌های مدل

### امنیت و سازمان
| مدل | نقش |
|---|---|
| `User` | کاربران (نقش admin/operator/viewer + isSupervisor + قفل تلاش ورود) |
| `Session` | نشست‌های ورود (توکن + انقضا) |
| `AuditLog` | لاگ عملیات (کاربر، عملیات، موجودیت، قبل/بعد) |
| `Company` | شرکت‌ها (چندشرکتی) + لوگو + کدهای بیمه/مالیاتی |
| `FiscalYear` | سال‌های مالی شمسی هر شرکت (تا jy=۱۵۰۰) |
| `FySetting` | عوامل پیش‌فرض هر سال: نرخ اضافه‌کاری، سقف‌ها، درصدها |
| `AppSetting` | تنظیمات عمومی کلید/مقدار |

### پرسنل
| مدل | نقش |
|---|---|
| `Personnel` | مشخصات پرسنل (کد پرسنلی یکتا) |
| `Contract` | قراردادها — شامل درصدهای شخصی بیمه (`sso_*_pct` = ۷/۲۰/۳) |
| `Decree` | احکام حقوق (لیست احکام) |
| `Loan` | وام‌ها |
| `Advance` | مساعده‌ها |
| `Leave` | مرخصی‌ها |

### شیفت و حضور
| مدل | نقش |
|---|---|
| `Shift` | تعریف شیفت (ساعت ورود/خروج) |
| `ShiftAssignment` | انتساب شیفت به پرسنل — شامل شیفت شخصی و گرید و دقایق گذشت |
| `ShiftOverride` (v۱.۴) | شیفت روزانه/تک‌روزه — استثنای یک روز مشخص برای یک فرد: kind=off (تعطیل) / custom (ساعت خاص startMin-endMin) / shift (شیفت تعریف‌شده)؛ یکتا روی (personnelId, jy, jm, jd) و دارای بالاترین اولویت در موتور شیفت |
| `AttendanceMonth` | ماه‌های واردشده از دستگاه (هر رکورد = یک ورودی دستگاه) |
| `AttendanceDaily` | کارکرد روزانه هر پرسنل (محاسبه‌شده) |

### حقوق
| مدل | نقش |
|---|---|
| `PayrollPeriod` | دوره حقوق (سال/ماه) + وضعیت: پیش‌نویس/تاییدشده/پرداخت‌شده |
| `PayrollLine` | سطر حقوق هر پرسنل در هر دوره (درآمد/کسور/خالص) |
| `PayrollSummary` | جمع دوره |
| `PayrollManual` | اقلام دستی (اضافه/کسر دستی) |
| `PayrollItemConfig` | پیکربندی اقلام حقوق (عناوین و فعال/غیرفعال) |

### مالیات و بیمه
| مدل | نقش |
|---|---|
| `TaxBracket` | پلکان مالیات (WP/WH) — ستون‌های ۲۳ و ۳۹ فرم‌های مالیاتی |

### سایر
| مدل | نقش |
|---|---|
| `ReportDef` | تعریف گزارش‌های ذخیره‌شده گزارش‌ساز |
| `InstalledModule` | ماژول‌های نصب‌شده (قابلیت توسعه آینده) |
| `CalendarEvent` | رویدادهای تقویم (تعطیلات، یادآورها) |

## نکات مهم

1. همه تاریخ‌ها **شمسی** ذخیره می‌شوند (jy/jm/jd یا رشته)؛ تبدیل فقط از طریق
   `src/lib/core/jalali.ts` انجام شود، هرگز با کتابخانه میلادی.
2. مبالغ به **ریال** و به‌صورت عدد صحیح ذخیره می‌شوند.
3. اعداد در نمایش باید با توابع `src/lib/core/numbers.ts` فارسی شوند.
4. `DATABASE_URL` در حالت وب از `.env` خوانده می‌شود؛ در exe، Electron آن را به
   `%APPDATA%/PayrollSystem/data/payroll.db` تنظیم می‌کند (نگاه کنید به
   `desktop/main.js` → متغیر `DB_DIR`).
